# 部署文档 · 宝塔面板 + Python 项目

全程鼠标操作，不碰命令行。前提：香港服务器（Debian）已装好宝塔面板，域名已能解析到这台服务器的 IP。

## 总览（8 步）

| # | 做什么 | 在哪做 |
|---|---|---|
| 1 | 装 MySQL 8.0 | 宝塔软件商店 |
| 2 | 建数据库和数据库账号 | 宝塔「数据库」 |
| 3 | 上传项目包并解压 | 宝塔「文件」 |
| 4 | 创建 Python 项目并启动 | 宝塔「网站 → Python 项目」 |
| 5 | 绑定域名 | 项目里的「域名管理」 |
| 6 | 申请 SSL 并强制 HTTPS | 生成的站点 → SSL |
| 7 | 跑安装向导 | 浏览器访问 `/install` |
| 8 | 验收 | 浏览器 + 日志 |

---

## 1 · 安装 MySQL

宝塔「软件商店」→ 搜 `MySQL` → 安装 **8.0**。装完记下 root 密码（在「数据库」页能看到）。

> 不用在命令行改任何 MySQL 配置。时区由应用在建立连接时统一 `SET time_zone = '+08:00'` 处理。

## 2 · 建数据库和账号

宝塔「数据库」→ **添加数据库**：

- 数据库名：`license`
- 用户名：`license`
- 密码：点「随机」生成一个，**复制下来**
- 访问权限：`本地服务器`

宝塔会自动建库并建好这个账号。这比让安装向导拿 root 去建库更干净。

> 注意：宝塔这里的库默认字符集可能是 `utf8mb3`。建完后进「管理 → 改密码」旁边没有改字符集的地方，需要在向导第 3 步执行 `schema.sql` 前先执行一次
> `ALTER DATABASE \`license\` CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;`
> 这一句在向导的 SQL 预览框里粘贴执行即可。

## 3 · 上传项目包

宝塔「文件」→ 进入 `/www/wwwroot` → 新建目录 `license` → 上传项目压缩包 → 右键 **解压**。

解压后目录结构应该是：

```
/www/wwwroot/license/
├── main.py               # FastAPI 入口，里面有 app = FastAPI()
├── requirements.txt      # 全部依赖
├── config.json           # 安装向导生成，现在还没有
├── app/
│   ├── config.py         # 读写 config.json
│   ├── db.py             # SQLAlchemy async engine / session
│   ├── models.py         # ORM 模型
│   ├── api.py            # /api 三个业务接口
│   ├── admin.py          # sqladmin 管理后台
│   ├── install.py        # 安装向导
│   └── templates/        # Jinja2 模板
└── sql/
    └── schema.sql        # 建表脚本
```

## 4 · 创建 Python 项目

宝塔「**网站 → Python 项目 → 添加项目**」：

| 字段 | 填什么 |
|---|---|
| 项目名称 | `license` |
| 项目路径 | `/www/wwwroot/license` |
| Python 版本 | `3.11`（面板里没有就点安装，装上 Python 3.10+ 都行） |
| 框架 | `ASGI`（FastAPI 属于这一类） |
| 启动文件 / 应用 | `main.py`（或 `main:app`，按面板给的输入框填） |
| 端口 | `8000` |
| 依赖文件 | 勾选安装 `requirements.txt` |
| 开机自启 | **打开** |

**关键一点**：让项目监听 `127.0.0.1`，不要监听 `0.0.0.0`。这样外部无法直连 8000 端口，一切流量都必须经过宝塔生成的站点进来，多一层保护。启动命令写成：

```
uvicorn main:app --host 127.0.0.1 --port 8000
```

点「确定」后等依赖装完、进程起来。**装依赖这一步可能要几分钟**，别急着往下走。

## 5 · 绑定域名

在刚创建的项目里点「**域名管理**」→ 添加你的域名 → 保存。

宝塔会自动生成一个站点和 Nginx 配置。**这一步之后先去验一下**：

- 浏览器打开 `http://你的域名`，能打开安装向导就对了
- 如果打不开（502 或空白），去「网站」里找到这个站点 → 「配置文件」，确认里面有 `location /` 那段代理到 `127.0.0.1:8000` 的配置。个别宝塔版本不会自动生成，需要手动补：

```nginx
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## 6 · 申请 SSL

在这个站点里 → 「SSL」→ 「Let's Encrypt」→ 勾选域名 → 申请 → 成功后打开「**强制 HTTPS**」。

Let's Encrypt 证书 90 天有效，宝塔会自动续签并自动重载，你什么都不用做。

> 如果申请失败：先确认云服务商的安全组放行了 **80 和 443**（宝塔「安全」页也要放行）。Let's Encrypt 的验证需要 80 端口可达。

## 7 · 跑安装向导

浏览器打开 `https://你的域名/install`，按提示走：

1. **环境自检** — 看有没有依赖没装上
2. **数据库** — 填第 2 步记下的信息：主机 `127.0.0.1`、端口 `3306`、用户 `license`、密码（第 2 步复制的）、库名 `license`。点「测试连接」
3. **初始化表结构** — 页面会显示 `schema.sql` 的内容，点执行
4. **管理员账号** — 这是后台登录用的（不是给用户用的）
5. **站点设置** — 域名、试用天数（1 天）、后台路径（`/admin`）
6. **完成** — 生成 `config.json`

装完之后 `/install` 自动失效。

## 8 · 验收

| 检查 | 期望 |
|---|---|
| `https://域名/admin` | 出现登录页，用第 4 步的账号能登进去 |
| 后台里 | 能看到 `license_user` / `license_order` / `admin_user` 三张表 |
| 客户端申请试用 | 返回「申请已通过」，后台里能看到这条新记录 |
| 再申请一次 | 返回「不支持多次试用」 |
| 校验一次 | 返回「未过期」，后台里 `count` +1、`last_time` 更新 |
| 把 `exptime` 改成过去时间后再校验 | 返回「已过期」，且 `count` **没有**变化 |
| 宝塔「Python 项目 → 日志」 | 无异常堆栈 |
| 重启服务器 | 应用自动起来（开机自启生效） |

## 常见问题

**打开域名是 502**
进程没起来，或者反代没配好。先看「Python 项目 → 日志」有没有报错；再看第 5 步的 `location /` 配置在不在。

**`pip` 装依赖失败**
多半是某个包含 C 扩展的包在 Debian 上缺编译环境。解决办法是换纯 Python 的同类包（这也是为什么选 `aiomysql` 而不是 `asyncmy`）。日志里会有具体包名。

**数据库连不上**
依次检查：库和账号是不是第 2 步建的、密码有没有复制错、MySQL 是不是在运行（宝塔「数据库」页能看到状态）。

**登录后台后一直跳回登录页**
`config.json` 里的 `secret_key` 读不到或为空。删掉 `config.json` 重新走一遍安装向导即可。

**手机能打开，电脑打不开（或反之）**
检查云服务商安全组和宝塔「安全」页里 443 是否放行。

**证书过期**
宝塔默认自动续签。若失败通常是 80 端口被占用或被云厂商拦截，去站点 SSL 页看续签任务的报错。
