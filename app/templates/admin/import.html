导入旧数据

从旧系统导出的 JSON 或 CSV 都可以直接传上来。列名按旧表的名字识别， 多出来的列（比如 id）会被忽略；已经存在的记录会跳过，不会覆盖现有数据。 所以传错文件、重复传，都不会弄坏数据。

授权账户（旧表 tooltype）

需要的列：typekey、addtime、exptime、last_time、user、email、count

旧系统里 addtime / exptime 存的是 UTC，last_time 存的却是北京时间 —— 这是历史遗留的不一致。实测确认过：同一个核销动作写进两张表的时刻正好差 8 小时。 数据如果本来就是你手工维护的，把勾去掉。

核销记录（旧表 toolorder）

需要的列：ordernumber、typekey、ordertime、usetime、money、name、sku

这两个时间在旧系统里已经是北京时间，原样搬过来，不做转换。

怎么导出

在 supabase 控制台打开 Table Editor → 选表 → 右上角导出。JSON 和 CSV 都行，两张表各导一次。
