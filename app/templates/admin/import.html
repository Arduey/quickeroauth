导入旧数据

从旧系统导出的 CSV 可以直接传上来。列名按旧表的名字识别，多出来的列会被忽略； 已经存在的记录会跳过，不会覆盖现有数据。

授权账户（旧表 tooltype）

需要的列：typekey、addtime、exptime、last_time、user、email、count

旧系统里 addtime / exptime 存的是 UTC，last_time 存的却是北京时间 —— 这是历史遗留的不一致，所以单独给了个开关。数据如果本来就是你手工维护的，把勾去掉。

核销记录（旧表 toolorder）

需要的列：ordernumber、typekey、ordertime、usetime、money、name、sku

这些时间在旧系统里已经是北京时间，原样搬过来。

从旧系统导出 CSV

在 supabase 控制台打开 Table Editor → 选表 → 右上角的导出按钮 → CSV。 两张表各导一次，然后回到这个页面上传。
