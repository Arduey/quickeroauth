接口说明

三个接口，用于客户端申请试用、校验授权、核销订单。全部为 POST，请求与响应都是 JSON。

通用约定

响应包 { "code": "...", "message": "...", "data": {...} }
状态码 业务结果一律 200，靠 code 区分；仅请求格式非法或服务自身出错才用非 200
时间格式 YYYY-MM-DD HH:MM:SS，北京时间，不带时区后缀
message 中文提示，可直接展示给用户；判断逻辑请用 code，不要比对文案

const res = await fetch("{{ site_url }}/api/verify", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ typekey: "Pro-8f3a91c2" }),
});
const data = await res.json();
if (data.code === "ACTIVE") {
  // data.data.exptime 是到期时间
}

Python

import requests

resp = requests.post(
    "{{ site_url }}/api/verify",
    json={"typekey": "Pro-8f3a91c2"},
    timeout=5,
)
data = resp.json()
print(data["message"])
